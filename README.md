# Olympus Campus

Aplicación privada para organizar materias y trabajos prácticos, guardar materiales en Google Drive y coordinar las sesiones nativas de Claude y ChatGPT.

La interfaz web vive en `web/` y la aplicación macOS en `desktop-poc/`. La guía de instalación, uso y verificación está en [desktop-poc/README.md](desktop-poc/README.md).
